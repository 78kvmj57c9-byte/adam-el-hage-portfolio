# CleanCSV

A small Python utility for cleaning repeatable CSV exports.

## What it demonstrates

- trims whitespace
- preserves a predictable schema
- removes exact duplicate records
- writes a cleaned CSV
- produces a human-readable quality report
- works with local files and does not require sending data to a third-party service

## Run

```bash
python clean_csv.py sample.csv cleaned.csv
```

This is a portfolio demonstration. A paid version would be adapted only after the real source schema, validation rules and desired output are agreed.
