# ReviewPulse

A browser-based portfolio prototype for customer-feedback analysis.

## Current features

- CSV upload
- automatic rating/score column detection
- automatic comment/feedback/review column detection
- average rating
- 1–5 distribution
- low-score queue (ratings 1–2)
- positive-share metric (ratings 4–5)
- recurring-word frequency view
- low-score CSV export

## Recurring-service test

- €69/month: one monthly export and management summary
- €129/month: weekly refresh and recurring complaint notes
- €249/month: multiple agreed sources, weekly report and one monthly improvement review

These are test offers. They are not market-rate claims or guaranteed revenue.
