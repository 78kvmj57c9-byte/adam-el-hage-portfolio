# QuoteFlow

QuoteFlow is a customizable spreadsheet model for small service businesses.

It is designed to help a business compare estimated delivery cost, sell price, gross profit and gross margin before sending a quote.

The working Excel version includes:

- editable service defaults
- line-item quote builder
- cost and revenue calculations
- VAT field
- gross-profit and margin checks
- simple commercial dashboard

Proposed customization range: $150–$350 depending on the input rules and requested output.
