# OpsPulse

A zero-install browser demo for turning a CSV export into a fast operational view.

## Current demo

- CSV upload
- row/column count
- exact duplicate-row detection
- missing-cell count
- data-completeness score
- simple numeric aggregation
- preview table
- cleaned CSV export with exact duplicate rows removed

## Commercial direction

OpsPulse is being tested as a managed recurring reporting service rather than a promise of fully automated SaaS infrastructure.

Proposed test packages:

- Starter: €79/month — monthly refresh, one source, one dashboard, concise summary
- Growth: €149/month — weekly refresh, two dashboards, anomaly notes
- Ops: €299/month — multiple agreed sources, weekly reporting, KPI pack, one monthly improvement sprint

Production integrations, hosting and paid APIs are scoped separately after a buyer exists.
