# Project rules

1. No fabricated client results or fake reviews.
2. Demonstrations use synthetic or owned data.
3. Production work starts only after scope, access, acceptance checks and payment terms are agreed.
4. Client-owned hosting, SaaS subscriptions and usage charges are separate unless explicitly included.
5. Security testing is performed only on systems the client owns or has explicit authorization to test.
6. One revision round is included only where the project quote says so; new requirements are re-scoped.
