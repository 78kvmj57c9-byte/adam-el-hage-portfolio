# 1. THE UMBRELLA

NOT THE SCRIPT is no longer only an FC website.

It is the umbrella world for everything we build.

- **NOT THE SCRIPT** = master universe / company / platform.
- **SkillIssue** = public face / mascot / character.
- **The Pitch** = original FC universe.
- **Final Boss** = crown jewel.
- **The Labs** = AI / experiment / R&D products.
- **Market District** = business systems.
- **The Forge** = custom software, websites, automation and freelance builds.
- **Life District** = personal operating systems.
- **Creator Quarter** = creator/media systems.
- **Research / Genesis** = future invention / deep R&D worlds.
- **My Career** = universal account/profile/progress layer.
- **Arsenal** = things a user owns, subscribes to, or has access to.

The original FC world is preserved as a major continent inside the larger NOT THE SCRIPT universe.

---

# 2. GLOBAL CREATIVE RULE

The website must feel like entering a game / world, not browsing a normal website.

Do not build:
Logo → Hero → cards → pricing → footer.

Build:
cinematic entry → living scene → world selection → travel → rooms → experiences → access.

Reference motion principles from the supplied videos:
- full-screen scenes;
- objects continue between sections;
- camera / zoom / travel transitions;
- typography participates in the scene;
- motion continues subtly at rest;
- different districts have different atmospheres;
- 3D objects feel like artifacts, not decoration;
- scroll is choreography, not simply vertical reveal.

# 14. COMMERCE / SECURITY

Public website is separate from sensitive Final Boss / Zen / internal infrastructure.

Frontend may request approved operations through authenticated APIs.
It must not receive private source, model internals, master scripts or secret files.

Use an established payment provider.
Never store raw card data.

Subscription system eventually requires:
- auth
- products
- prices
- entitlements
- renewals
- cancellation
- receipts
- support
- refunds/admin grants

# 16. MOBILE

Mobile is a separately designed experience.

- shorter intro
- lighter 3D
- optimized video
- touch-first controls
- fast CTA/access
- fewer simultaneous effects
- same identity, not a broken desktop shrink

Desktop receives the full cinematic version.
